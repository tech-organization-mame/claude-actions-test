# レビューデモ用: 仕込んだ問題の一覧（答え合わせ用）

`app.py` には、レビューのデモ用に次の問題を意図的に入れています。本番では使わないでください。

| 箇所 | 問題 |
| --- | --- |
| `API_KEY` | シークレットのハードコード |
| `hash_password` | MD5 によるパスワードハッシュ（ソルトなし） |
| `register` / `login` | SQL インジェクション |
| `calculate` | `eval` による任意コード実行 |
| `ping` | `shell=True` によるコマンドインジェクション |
| `read_file` | パストラバーサル（`../` を検証していない） |
| `load_session` | 信頼できないデータの `pickle.loads` |
| `init_db` / 各関数 | DB 接続を閉じていない |
| `average` | 空リストでゼロ除算 |
| `last_n` | off-by-one（`n` 件より1件多く返る） |
| `add_item` | ミュータブルなデフォルト引数 |
